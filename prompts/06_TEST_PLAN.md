# Prompt 06 — QA Test Plan

For feature [FEATURE], inspect the spec and implementation, then produce:
1. happy-path tests
2. invalid-input tests
3. boundary/edge cases
4. multiplayer consistency tests if relevant
5. persistence/reconnect tests if relevant
6. security/abuse cases
7. visual/manual test checklist
8. regression tests for previously fixed defects

For each test include setup, action, expected result and whether it can be automated. Then implement only tests if asked. Never mark tests passed unless actually run.
