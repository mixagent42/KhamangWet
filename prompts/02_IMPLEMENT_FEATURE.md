Out of scope:

Workflow:
1. Inspect repository and git status.
2. Explain current behavior and dependencies briefly.
3. Propose a small plan and list files to change.
4. Implement only this feature.
5. Add unit/integration tests appropriate to the change.
6. Run relevant test, typecheck and build commands; report actual output.
7. Review diff for unrelated edits, security risks and API breaks.
8. Update docs if behavior or contracts changed.

Do not claim completion if a test could not run. Do not replace existing architecture with a new one unless asked.
