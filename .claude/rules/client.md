# Client Rules
- Client is presentation/input, not authority for combat outcomes, loot, currency or inventory ownership.
- Keep rendering code separate from game rules and network transport.
- Dispose observers, meshes, textures and listeners when scenes/components are removed.
- Test sprite pivots, occlusion, facing and VFX readability in representative scenes.
- Do not add assets with unclear licensing/provenance.
